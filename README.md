# 地图设计器

一个像素风地图的编辑器和生成器：浏览器里的可视化编辑界面、一个 MCP 接口，以及一个按地理规律生成岛屿与谷地的生成器。地图逻辑上是格子，画面是星露谷式的连续地表，而且整张都是会动的（风吹草、浪、水流、瀑布）。

仓库里带了一张示例地图 `main_valley`（320×240 格的海岛谷地）。

## 运行

需要 Python 3.10+，以及 numpy 和 Pillow：

```bash
pip install -r requirements.txt
```

启动编辑器，然后用浏览器打开 http://127.0.0.1:8765/ ：

```bash
python server.py
```

图块集 `data/maps/tileset.json` 是由 `seed.py` 生成的，改了 `seed.py` 后可以重建：

```bash
python seed.py --force
```

跑测试：

```bash
python -m unittest test_mapkit test_geo
```

## 编辑器

- **两种查看方式**（V 切换）：「全图」把整张地图缩到窗口里，只画静态的一帧；「行走比例」按游戏里的大小看，WASD 平移，不能缩放，只渲染看得到的部分，可以开关动画（P）。
- 三层：**地面**（连续的材质，边界自然起伏）、**植被**（长在地面上的一层，可割、可踩、可藏身，画成成片的草叶）、**物件**（树、石头等可跨多格的精灵）。
- 笔刷、擦除、矩形、填充、吸取；撤销/重做；格线（G）、等高线（H）；状态栏显示光标所在格的地面、植被、物件、高度和生物群系。
- 地面材质和物件精灵都能在界面里编辑（像素画编辑器、材质参数编辑器）。
- 导出（`export/`）：物件精灵逐帧打包成 `tiles.png` + `tiles.json`，每张地图导出静止地面、各帧的差异层、物件清单和每格植被。

服务器在多个进程里并行渲染地图块，并缓存渲染过的块。

## MCP

`mcp_server.py` 是一个 stdio MCP 服务器，提供看图、编辑、新建图块、按地理规律生成地图、导出等工具。在 MCP 客户端里这样配置：

```json
{"mcpServers": {"mapdesigner": {"command": "python", "args": ["/path/to/mcp_server.py"]}}}
```

## 按地理规律生成

`geo.py` 分两级：先在粗格网上推演整个谷地，再切一块放大成一格一步的地图。

- **地形**：地貌演化模型，构造抬升与河流下切（水流功率定律，沿汇流顺序隐式求解）相抗，加坡面蠕动、谷底淤积。参数按真实谷地的统计量（陡坡占比、平地占比、面积高程积分）校准。
- **水文**：填洼、汇流、河网；河道按流量定宽，曲流只在河漫滩上，水面在硬岩和急处集中跌落成瀑布，弯道内侧有点沙洲。
- **海岸**：海蚀平台、潮池、海蚀柱、海蚀洞、卵石脊、沙嘴与潟湖、盐沼和潮沟。
- **高处**：雪线、泥炭沼、高山垫状植物、矿脉露头。
- **生物群系**：仿照 Minecraft，先算温度、湿度、离海远近、坡度几个平滑的场，再查表得到群系（草原、花海、干草原、阔叶林、白桦林、幽暗林、针叶林、荒原、高山草甸、河岸、沼泽，以及由地形决定的海滩、石岸、盐沼、泥炭沼、裸岩、雪坡）。每个群系规定地表、植被、树种和密度。
- **可走**：崖壁只在坡度超过 40° 的地方；生成后自动开坡道、铺浅滩、挪开堵路的树，保证整张图走得通。

`designs/main.json` 是示例地图的设计文件：写明海岸线、谷轴、山、硬岩、台地、沙嘴、矿脉的位置，地形按上面的规律长出来。改这份文件再生成，就是精调。

### 真实地形数据（可选）

生成器默认不需要任何外部数据。如果想用真实谷地作对照，或跑依赖它的那几个测试，可以下载：

```bash
python dem/fetch.py
```

数据来自 [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)（Mapzen terrarium 编码，托管于 AWS Open Data）。署名要求见 `dem/sources.json` 和 <https://github.com/tilezen/joerd/blob/master/docs/attribution.md>。

## 给 Claude Code 用的像素画技能

`.claude/skills/pixel-art/` 是一个 Claude Code 技能：教它怎么用 `pixelkit.py` 画像素素材（先剪影、再按色阶从左上打光、预览后检查、按调色板校验），附一份常见问题的修补手册。在这个仓库里用 Claude Code 时，让它画树、石头、地面图块之类，它会按这个流程来。

## 文件

| 文件 | 内容 |
|---|---|
| `mapkit.py` | 地图与图块的数据、读写、校验、导出 |
| `render.py` | 渲染：材质、台阶与崖壁、植被、物件、动画 |
| `geo.py` | 按地理规律生成 |
| `trees.py` | 树的像素画（叶团法） |
| `seed.py` | 起始图块集 |
| `pixelkit.py` | 像素画小工具库 |
| `server.py`, `web/` | 编辑器 |
| `mcp_server.py` | MCP 接口 |
| `palette.json` | 调色板；图块只能用这里的颜色 |
